# 천안 두정동 국제태권도장 — 홈페이지 · 도장운영시스템

정적 웹 애플리케이션입니다. 빌드 과정 없이 그대로 호스팅할 수 있습니다.

## 파일 구성

```
kukje-taekwondo-web/
├── index.html      공개 홈페이지 + 도장운영 관리자 (한 파일에 함께)
├── styles.css      스타일 (네이비·골드·화이트, 반응형)
├── app.js          모든 동작 (localStorage 저장)
└── assets/         실제 도장 사진 + 카톡 채널 QR
```

## 실행·배포

- **바로 보기**: 폴더째로 아무 정적 호스팅(GitHub Pages, 네이버 마이플레이스 연결 웹호스팅, 카페24, AWS S3 등)에 올리거나, 로컬에서는 `python3 -m http.server 8080` 후 `http://localhost:8080` 접속.
- CDN 폰트(Pretendard·Noto Sans KR)를 사용하므로 인터넷 연결이 필요합니다. 완전 오프라인 환경이면 index.html의 폰트 `<link>` 2줄을 지워도 동작합니다(시스템 폰트로 대체).

## 관리자 모드

- 상단 네비게이션의 **[도장운영 관리자]** 버튼(또는 푸터 링크) → PIN 입력.
- **기본 PIN: `0000`** — 관리자 → 공지·시간표·설정 → 관리자 PIN 변경에서 수정 가능.
- "PIN 없이 체험용으로 둘러보기" 버튼도 있습니다.
- 데이터는 브라우저 `localStorage`에만 저장됩니다(키: `kukje_data_v1`).
  - 초기에 샘플 데이터(원생 12명·출결·수납·심사·문의·공지·시간표)가 채워져 있습니다.
  - **JSON 백업 내보내기 / JSON 복원 / 샘플 초기화**를 관리자 좌측 하단·설정 화면에서 제공.
  - 기기를 바꾸기 전에는 반드시 JSON 백업을 해 두세요.

## 홈페이지 ↔ 관리자 연동

| 관리자에서 수정 | 홈페이지 반영 |
|---|---|
| 공지 등록/수정/삭제 | 공지사항 섹션 즉시 반영 |
| 시간표 추가/수정/삭제 | 프로그램·시간표 즉시 반영 |
| 도장 전화·운영시간·수련비·주소 | 페이지 전체(헤더/푸터/신청/오시는 길) 즉시 반영 |
| 홈페이지 무료체험 신청폼 제출 | 관리자 [체험·상담 문의]에 자동 접수 |
